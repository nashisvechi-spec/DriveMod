Первая Android-версия DriveMod.

- Выбор навигации и музыки из установленных приложений; поиск и реальные значки.
- Запуск выбранной пары через системный разделённый экран.
- Проверка появления двух окон, сообщения о несовместимости прошивки.
- Четыре настраиваемых ярлыка, панель высотой 1/9, сворачивание и меню удерживанием.
- Чёрный и тёмно-синий интерфейс, логотип DM.
- Без root, ADB и беспроводной отладки. Нет разрешения на интернет.

После установки выберите приложения и включите службу DriveMod в специальных возможностях. На Android 13+ может понадобиться разрешить ограниченные настройки в сведениях о приложении.

Панель накладывается на нижний край сторонних приложений. Её можно свернуть, чтобы открыть закрытые элементы. Размер и направление окон определяет Android; совместимость конкретного навигатора и музыкального приложения зависит от устройства.

APK подписан постоянным ключом DriveMod. Исходники, тесты и процесс сборки находятся в этом репозитории. Яндекс API пока не подключён.
