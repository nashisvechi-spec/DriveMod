DriveMod 0.1.1 — исправление запуска двух приложений на Android 12L и новее.

- Запуск пары через временный экран DriveMod: Android получает контекст Activity, необходимый для открытия соседнего окна.
- Навигация и музыка остаются отдельными установленными приложениями. Нижняя панель содержит четыре настраиваемых ярлыка.
- Исправлена установка Android SDK в GitHub Actions: убран недоступный устаревший пакет tools.
- Расширены проверки состояния запуска и диагностика эмулятора.

APK подписан тем же постоянным ключом DriveMod и обновляет версию 0.1.0 без удаления настроек. Для работы включите службу DriveMod в специальных возможностях Android.

Направление, размеры и поддержка разделённых окон зависят от устройства и выбранных приложений. Панель накладывается на нижний край; нажмите полоску, чтобы её свернуть. Яндекс API пока не подключён.
