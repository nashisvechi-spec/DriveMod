# DriveMod

Автомобильный экран для Android: выбранная навигация, выбранная музыка и четыре ярлыка. Цвета бренда — тёмно-синий и чёрный.

## Установка

Последний подписанный релиз: [**DriveMod-0.1.1.apk**](https://github.com/nashisvechi-spec/DriveMod/releases/download/v0.1.1/DriveMod-0.1.1.apk).

Новые сборки создаются только на GitHub: откройте [Actions → Build APK](https://github.com/nashisvechi-spec/DriveMod/actions/workflows/android.yml), выберите успешный запуск и скачайте артефакт **DriveMod-APK**. Внутри ZIP находится один установочный файл `DriveMod-<версия>-debug.apk`.

Автосборка использует отладочную подпись Android. Такой APK не обновляет подписанный релиз 0.1.1 поверх: для перехода на отладочную сборку потребуется удалить релиз, что удалит его настройки. Постоянный ключ релиза хранится вне GitHub.

1. Установите APK на Android 8.0 или новее. Автоматический вход в разделённый экран зависит от Android и прошивки; основной сценарий — телефон в портретной ориентации.
2. На главном экране выберите навигацию и музыку. Список составляется из реально установленных приложений, подходящие выводятся выше. Можно выбрать приложение вне рекомендаций.
3. При первом использовании откройте оба приложения отдельно и завершите их начальную настройку. Удерживание карточки DriveMod открывает соответствующее приложение.
4. Включите **«DriveMod — два окна и панель»** в специальных возможностях Android. В приложении есть кнопка перехода и объяснение назначения службы.
5. Нажмите **«Открыть два приложения»**. Размер окон меняйте системным разделителем.

На Android 13+ при установке APK система может блокировать специальную возможность. В этом случае откройте сведения о DriveMod → меню ⋮ → «Разрешить ограниченные настройки», затем включите службу.

## Нижняя панель

- Четыре ярлыка выбираются из установленных приложений в настройках. На главном экране удерживание ярлыка также открывает его выбор.
- В развёрнутом виде панель занимает 1/9 доступной высоты экрана, без системных панелей.
- Нажмите полоску над ярлыками, чтобы свернуть или развернуть панель.
- Удерживайте полоску или любой ярлык, чтобы открыть меню: повторный запуск пары, настройки, сворачивание, завершение режима.
- По умолчанию панель скрывается при появлении клавиатуры и на экране блокировки.

## Что важно для версии 0.1

Это **два настоящих приложения в системном split-screen**, а не карта-заглушка или WebView. Внешний вид каждого окна принадлежит выбранному приложению.

Обычный Android APK не может произвольно встраивать чужие приложения в свои View и зарезервировать для них собственную область 8/9 экрана. Поэтому панель DriveMod **накладывается** на нижний край и может закрывать часть второго приложения. Её можно свернуть. Положение окон, минимальные размеры, направление разделения и возможность автоматического запуска определяются Android и прошивкой. В альбомной ориентации Android может расположить окна рядом вместо друг над другом.

Если прошивка отклонила автоматический запуск пары, DriveMod сообщает об этом, а не выдаёт полноэкранный запуск за успешное разделение. Можно открыть выбранную пару через «Недавние» → разделённый экран, оставив панель DriveMod.

Начиная с версии 0.1.1 на Android 12L и новее пара запускается через временный экран DriveMod: он открывает одно приложение рядом, затем заменяет себя вторым. Это сохраняет необходимый Android контекст Activity для `FLAG_ACTIVITY_LAUNCH_ADJACENT`. На Android 8–12 используется системное действие службы специальных возможностей.

Это самостоятельный экран смартфона, без проекции на автомобильную мультимедиа через протокол Android Auto. Яндекс API в этой версии не используется.

## Приватность

У приложения нет разрешения `INTERNET`, доступа к геолокации, контактам, уведомлениям, файлам или микрофону. Эти разрешения могут отдельно требоваться выбранному навигатору и музыкальному приложению.

Служба специальных возможностей получает события смены окон. Она использует только имя пакета корневого окна и его прямоугольник, чтобы определить, открылись ли два приложения; дочерние узлы, тексты и поля ввода не обходятся. Список приложений и выбранные ярлыки хранятся локально. Служба включается и выключается пользователем в настройках Android. Root, ADB и беспроводная отладка для работы DriveMod не нужны.

## Сборка и проверки

JDK 17, Android SDK 35, Build Tools 35.0.0. Gradle Wrapper 8.11.1 и AGP 8.9.2 закреплены в проекте.

```sh
./gradlew :app:testReleaseUnitTest :app:lintRelease :app:assembleRelease
```

Без конфигурации подписи Gradle создаёт `app-release-unsigned.apk`. Публикуемый APK подписывается отдельным постоянным ключом; приватный ключ и пароль в репозиторий не входят. Для обновления установленной версии нужен тот же ключ и больший `versionCode`.

GitHub Actions выполняет только `:app:assembleDebug` и сохраняет один APK в артефакте `DriveMod-APK`. Отдельные тесты, lint, эмулятор, тестовые приложения и автоматическая публикация Releases в автосборке не запускаются. Исходники тестов остаются доступными для ручной проверки.

Для новой версии: обновить `version.properties`, собрать release APK, подписать его прежним ключом, положить в `dist/`, обновить `dist/SHA256SUMS` и добавить описание в `docs/releases/`. Файлы подписи хранить вне Git. Автоматическая подпись в CI может быть добавлена через секреты репозитория; сейчас ключ остаётся вне GitHub.

Готовый отладочный APK содержит только приложение DriveMod; модули `testnav` и `testmusic` в него не входят.
